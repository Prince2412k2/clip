# Plan: clippy v1

**Spec:** `docs/specs/2026-07-13-clippy-v1.md`
**Date:** 2026-07-13
**Strategy:** One person (orchestrator) lays fixed contracts + compiling skeleton, then
parallel Sonnet agents implement disjoint packages against those contracts, then
orchestrator integrates and verifies. No two agents touch the same file.

## Architecture / package layout

```
clippy/
  go.mod                          module "clippy", go 1.26, ZERO external deps (stdlib + shell-out)
  cmd/clippy/main.go              subcommand dispatch: serve | peers | target | on | off | status
  internal/
    payload/payload.go            Payload{ID,Kind,Mime,Name,Sha256,Size,Data}; MaxSize=20MB; hashing; cap check
    config/config.go              Config{Token,Target,SyncEnabled,RecvDir,Port}; JSON load/save in os.UserConfigDir
    clipboard/
      clipboard.go                Kind, Item, Clipboard interface, New() factory
      clipboard_linux.go          //go:build linux   — wl-clipboard shell-out (wl-paste --watch, wl-copy)
      clipboard_darwin.go         //go:build darwin  — pbcopy/pbpaste/osascript shell-out, poll changeCount
      clipboard_other.go          //go:build !linux && !darwin — stub returning ErrUnsupported
    tailnet/tailnet.go            Peer{Name,IP,Online}; Peers() via `tailscale status --json`
    transport/
      api.go                      route paths, header names, DTOs, Handler interface  [CONTRACT]
      client.go                   Client.Send(ctx, addr, *payload.Payload) — HTTP POST /v1/clip
      server.go                   http.Server, auth middleware, routing → Handler; static webapp mount
    daemon/daemon.go              Daemon implements transport.Handler; watcher loop; dedupe + echo suppression
    webapp/
      webapp.go                   embed.FS, GET / handler
      assets/index.html           static drop-zone UI (target picker, text box, file drop)
```

Design choices (rationale):
- **No cgo, no external Go deps.** Clipboard access via shelling out to `wl-copy`/
  `wl-paste` (Linux) and `pbcopy`/`pbpaste`/`osascript` (macOS). Preserves the single
  static binary + trivial cross-compile goal (DESIGN.md), and avoids X11/AppKit build
  headaches. Tailnet peers via `tailscale status --json`.
- **One HTTP listener per daemon, bound to the Tailscale IP** (FR-015). The CLI reaches
  it on that same IP (a local interface). All endpoints require the shared token
  (fleet is trusted); noted as acceptable for a personal fleet in v1.

## HTTP API contract (transport/api.go) — the shared truth

- `POST /v1/clip` — receive. Headers: `Authorization: Bearer <token>`, `X-Clippy-Kind`,
  `X-Clippy-Name`, `X-Clippy-Mime`, `X-Clippy-Sha256`. Body: raw bytes. → 200/401/413.
- `GET  /v1/status` — {version, sync_enabled, target, tailscale_ip}. Token.
- `POST /v1/target` — {target}. Token.
- `POST /v1/sync` — {enabled: bool}. Token.
- `GET  /v1/peers` — [{name, ip, online}]. Token.
- `POST /v1/send` — multipart relay from webapp/phone: fields target + text|file. Server
  relays to target's `/v1/clip`. Token.
- `GET  /` and `/assets/*` — webapp UI (served without token; API calls from the page
  carry the token the user entered).

`transport.Handler` interface (daemon implements; server calls):
```
Receive(kind, name, mime, sha string, body []byte) (status int, err error)
Status() StatusDTO
SetTarget(target string) error
SetSync(enabled bool) error
Peers() ([]PeerDTO, error)
Relay(target string, p *payload.Payload) error
```

## Correctness invariants (must hold — from FR-005/006)

- **Dedupe:** watcher tracks last-sent content hash; identical content sent at most once.
- **Echo suppression:** hashes written to the clipboard via `Receive`/`Set` are recorded;
  the watcher ignores a clipboard change whose hash is in the recently-received set.
  Prevents A→B→A ping-pong.

## Task breakdown

### Wave 0 — Foundation (orchestrator, sequential, before any agent)
- T0.1 `go.mod` + `cmd/clippy/main.go` dispatch skeleton.
- T0.2 `internal/payload/payload.go` (full).
- T0.3 `internal/config/config.go` (full).
- T0.4 `internal/clipboard/clipboard.go` interface + `clipboard_other.go` stub.
- T0.5 `internal/transport/api.go` (full contract) + `client.go` (full).
- T0.6 `internal/daemon/daemon.go` — full watcher loop, dedupe, echo suppression,
  Handler impl, coded against the clipboard/tailnet/transport interfaces.
- T0.7 `internal/tailnet/tailnet.go` — Peer type + `Peers()` stub (agent fills body).
- T0.8 `internal/transport/server.go` — stub returning not-implemented (agent fills).
- T0.9 `internal/webapp/webapp.go` + placeholder asset (agent replaces).
- **Gate:** `go build ./...` and `GOOS=darwin go build ./...` both green with stubs.

### Wave 1 — Parallel Sonnet agents (disjoint files, code against Wave-0 contracts)
- **A — Linux clipboard** (`clipboard_linux.go`): implement `Watch`/`Set`/`Read` via
  `wl-paste --watch`, typed reads (text, image/png, text/uri-list→read file bytes),
  `wl-copy`. Depends on: clipboard.go interface.
- **B — macOS clipboard** (`clipboard_darwin.go`): poll `NSPasteboard` change via
  `pbpaste`/`osascript`; text + PNG image + file-URL; `pbcopy`/osascript to set. Must
  compile under `GOOS=darwin`. Depends on: clipboard.go interface.
- **C — Tailnet** (`tailnet.go` body): parse `tailscale status --json` → online peers
  with tailnet IPs, self excluded. Depends on: tailnet.go types.
- **D — Transport server** (`server.go` body): http.Server bound to given addr, auth
  middleware, route table → `transport.Handler`, multipart `/v1/send` relay, mount
  webapp. Depends on: api.go contract, webapp.Handler.
- **E — Webapp** (`assets/index.html` + wire in `webapp.go`): responsive drop-zone page,
  token field (persisted in localStorage), target dropdown populated from `/v1/peers`,
  text box + file drop → `POST /v1/send`. Self-contained (no external CDNs).
- **F — CLI** (`internal/cli/cli.go` + wire into main): `peers`, `target <name>`, `on`,
  `off`, `status` — thin HTTP client to the local daemon; friendly output. Depends on:
  api.go, config.go.

### Wave 2 — Integration & verify (orchestrator)
- Wire main.go dispatch to real cli + daemon + server. `go build` + `go vet`.
- `GOOS=darwin go build ./...` to typecheck the macOS backend.
- End-to-end on Linux: run two daemons (two configs/ports on loopback+tailscale),
  copy text/image/file on one, assert it lands on the other (clipboard/recv dir).
- Verify SC-001..008 as far as a single Linux host allows (macOS runtime deferred).
- Run `verify-done`; commit.

## Risks
- macOS clipboard cannot be runtime-verified on this Linux host → cross-compile
  typecheck only; flagged for a real-device pass later.
- Auto-push + auto-set could loop → mitigated by echo suppression invariant (owned by
  orchestrator in T0.6, not delegated).
- `tailscale status --json` schema drift → parse defensively, tolerate missing fields.
